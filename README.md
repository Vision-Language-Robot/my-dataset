# MixOrchard-VL Dataset

Official repository of the **MixOrchard-VL** dataset, released with the paper:

> **LiteRef-Net for language-guided fruit selection and mask-based robotic harvesting**

## 📖 Overview

**MixOrchard-VL** is a vision-language referring perception dataset built for **language-guided selective fruit harvesting** in mixed orchard environments. Unlike conventional fruit detection datasets that only support closed-set recognition, MixOrchard-VL formulates harvesting target selection as a **task-conditioned grounding problem**: given an RGB image and a natural-language instruction, the model must produce a pixel-level mask of the *specific* fruit the instruction refers to.

Each evaluation sample consists of:

- an **RGB image** of a mixed-fruit / orchard-like scene,
- a **natural-language referring instruction**, and
- a corresponding **target mask**.

The instructions describe task-relevant constraints such as **fruit category, maturity state, color, occlusion condition, and spatial relation**, e.g.:

- *"the ripe apple located in the top-right cluster"*
- *"the red fruit on the left"*
- *"the occluded orange behind the branch"*

### Evaluation Splits

The dataset is divided **at the image level** to avoid image leakage between training and testing. Visually near-duplicate images are assigned to the same split, and the category distribution is preserved as much as possible.

| Split          | Images | Language–Mask Pairs | Purpose                                |
| -------------- | ------ | ------------------- | -------------------------------------- |
| Training set   | 11,712 | 80,481              | Model training                         |
| Validation set | 645    | 4,620               | Hyper-parameter / checkpoint selection |
| Test set       | 675    | 4,479               | Final evaluation                       |

## 🏷️ Annotation Pipeline

**Visual annotation (semi-automatic).** The Segment Anything Model (SAM) is first initialized with coarse bounding-box prompts to generate preliminary fruit masks. Since orchard scenes frequently contain severe leaf occlusion, fruit overlap, and branch interference, all generated masks are automatically verified by a vision-language model (Qwen3.8-VL): each segmented instance is judged as fruit or non-fruit (leaf, branch, background), and 283k false-positive instances are removed to ensure accurate target boundaries.

**Language annotation.** Referring expressions are generated by vision-language models (Qwen3.8-VL-4B deployed locally and Qwen3.8-Flash via cloud API) conditioned on numbered-box visual prompts, producing RefCOCO+-style expressions grounded in appearance (color, ripeness, size, occlusion, texture, shape) and spatial relations. A template-based fallback covers only 8 of 16,952 images (0.05%). All expressions pass automated JSON-format and referential-consistency checks.

## 🚀 Intended Use

MixOrchard-VL is designed for research on:

- **Referring image segmentation (RIS)** in agricultural scenes,
- **Vision-language grounding** under occlusion, clutter, and mixed maturity,
- **Task-conditioned target selection** for robotic selective harvesting,
- **Domain-shift evaluation** between web-sourced and field-captured orchard imagery.
